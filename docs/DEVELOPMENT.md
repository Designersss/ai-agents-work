# Разработка и приёмка

Основной план — #2. Первая поставка — #4 / #5 / #6, без серверной логики.

## Установка

1. Node.js >=22, pnpm 10.
2. `pnpm install`.
3. `pnpm dev`, затем http://localhost:3000.

## Проверки

- `pnpm lint` — ESLint + Next.js.
- `pnpm typecheck` — строгий TypeScript.
- `pnpm test` — unit-тесты набора demo fixtures.
- `pnpm build` — production build Next.js.

## Область QA

1. Desktop: 1440×900 — menu/header/карточки/активность.
2. Tablet: 768×1024 — работа сетки и navigation.
3. Mobile: 390×844 и 360×740 — диалоговое меню, scroll/focus/Escape.
4. Изменить диапазон 7/30; значения и график обязаны обновиться.
5. Изменить пространство «Atlas Studio» на «Личное»: показатели, интеграции и активность меняются, показывают empty states.
6. Недоступные разделы меню имеют состояние «Скоро», не вызывают ложных переходов.

**Скриншоты и визуальная приёмка требуются до merge.**

## Безопасность

Нет .env и API keys в UI. Значения полностью демонстрационные, помечены в интерфейсе. Секреты и денежные операции будут отдельно реализованы сервером по #7, #8, #13.
